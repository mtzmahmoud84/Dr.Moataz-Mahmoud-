# موقع د. معتز محمود رياض – استشاري جراحة العظام

موقع طبي عربي RTL (Static Website) جاهز للرفع على GitHub Pages أو أي استضافة Static.

## الملفات
- `index.html` — محتوى الموقع وهيكله.
- `styles.css` — التصميم المتجاوب.
- `script.js` — القائمة المتحركة، التنقل، ونموذج حجز الموعد عبر WhatsApp.
- `prompt-ar.txt` — Prompt عربي احترافي لإعادة توليد/تطوير الموقع باستخدام أي أداة AI.

## التشغيل محليًا
يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط.

## الرفع على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع الملفات الثلاثة الأساسية (`index.html`, `styles.css`, `script.js`) وملف `README.md`.
3. من Settings → Pages اختر النشر من Branch الرئيسي (عادةً `main`) ومن مجلد `/root`.
4. بعد النشر سيظهر الموقع على رابط GitHub Pages الخاص بالمستودع.

## التخصيص قبل النشر
- استبدل تمت إضافة صورة الطبيب في `assets/doctor.jpg` داخل `index.html` بصورة حقيقية واحترافية.
- أضف عنوان العيادة الفعلي مكان البطاقة الخاصة بالموقع.
- أضف مواعيد العمل والبريد الإلكتروني وروابط السوشيال ميديا عند توفرها.
- راجع الخدمات والحالات والأسئلة الشائعة للتأكد من مطابقتها لخدمات العيادة الفعلية.
- لا تضف أي مؤهل علمي أو شهادة أو خبرة غير مؤكدة.
