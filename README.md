# موقع د. معتز محمود رياض — استشاري جراحة العظام

موقع طبي عربي (RTL) من صفحة واحدة، مبني بـ HTML5 وCSS3 وJavaScript فقط، بدون Backend وبدون خطوات Build.
جاهز للنشر على GitHub Pages أو أي استضافة ثابتة (Static).

## محتويات المجلد

```
clinic-site/
├── index.html    ← هيكل الصفحة والمحتوى
├── styles.css    ← التصميم (الألوان والخط في أعلى الملف)
├── script.js     ← القائمة، القسم النشط، نموذج الحجز، سنة الحقوق
├── images/
│   └── doctor.jpg  ← صورة الطبيب (الواجهة الرئيسية وقسم «عن الطبيب»)
└── README.md     ← هذا الملف
```

## التشغيل محليًا

**الطريقة الأسرع:** افتح ملف `index.html` مباشرة في المتصفح.

**أو عبر خادم محلي بسيط** (اختياري):

```bash
cd clinic-site
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> خط Cairo يُحمَّل من Google Fonts، فيلزم اتصال بالإنترنت لظهوره. وبدون اتصال يعرض المتصفح خط Tahoma أو Segoe UI تلقائيًا.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثال: `dr-moataz-clinic`).
2. ارفع `index.html` و`styles.css` و`script.js` و`README.md` إلى جذر المستودع، **مع مجلد `images` كاملًا** (يحتوي على `doctor.jpg`) وإلا لن تظهر الصورة.
3. من المستودع: **Settings ← Pages**.
4. في **Build and deployment** اختر **Source: Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. بعد دقيقة تقريبًا يظهر الرابط أعلى صفحة Pages بالشكل `https://USERNAME.github.io/REPO/`.

**نطاق خاص (Domain):** من نفس صفحة Pages أضف النطاق في خانة **Custom domain**، ثم اضبط سجلات DNS كما يوضح GitHub.

## ما يجب استكماله قبل النشر

لم تُضَف أي بيانات غير مؤكدة عمدًا. الأماكن التالية جاهزة للتعديل، وكلها معلَّمة في `index.html` بتعليق يبدأ بـ **✏️ عدّل هنا**:

| البند | مكانه | ما تفعله |
|---|---|---|
| صورة الطبيب | `images/doctor.jpg` | موجودة بالفعل، وتظهر في الواجهة الرئيسية وقسم «عن الطبيب». لتغييرها استبدل الملف بصورة أخرى بنفس الاسم (نسبة 4:5 مناسبة، مثل 864×1080) |
| نبذة إضافية والمؤهلات | قسم «عن الطبيب» | أضف المؤهلات والخبرات بعد التأكد من دقتها |
| عنوان العيادة | قسم «التواصل» | استبدل نص `placeholder` بالعنوان واحذف الكلاس `placeholder` |
| مواعيد العمل | قسم «التواصل» | كما سبق |
| البريد الإلكتروني | قسم «التواصل» | كما سبق (يمكنك جعله رابط `mailto:`) |
| خريطة Google Maps | قسم «التواصل» | من Google Maps: مشاركة ← تضمين خريطة، ثم ضع كود `iframe` مكان محتوى `map-box` واحذف الكلاس `is-placeholder` |
| حسابات التواصل الاجتماعي | التذييل | فعّل القالب الموجود في التعليق بعد إضافة الروابط الحقيقية |
| رابط الموقع وصورة المشاركة | داخل `<head>` | أزل التعليق عن `canonical` و`og:url` و`og:image` وضع القيم الصحيحة |

### تعديل الخدمات أو الحالات
انسخ عنصر `<li class="card">` (للخدمات) أو `<li>` داخل `condition-list` (للحالات) وعدّل النص. إن أضفت خدمة جديدة فأضِف خيارًا مقابلًا في قائمة `select` داخل نموذج الحجز.

### الألوان والخط
في أعلى `styles.css` داخل `:root` ستجد المتغيرات (`--primary` و`--deep` و`--mint-50` ...). تغييرها يحدّث الموقع كله.

## كيف يعمل نموذج الحجز

- عند الضغط على «أرسل طلب الحجز عبر واتساب» يتحقق الموقع من الاسم ورقم الهاتف والخدمة.
- يُنشأ نص عربي منظم (الاسم، الهاتف، الخدمة، وصف الحالة) ويُفتح واتساب على الرقم `+201554764748`.
- **لا يتم إرسال أو تخزين أي بيانات على أي خادم.** الرسالة لا تصل العيادة إلا بعد أن يضغط المريض «إرسال» داخل واتساب.
- لتغيير رقم واتساب عدّل `whatsappNumber` في أعلى `script.js` (بالصيغة الدولية بدون `+`)، وعدّل روابط `tel:` و`wa.me` في `index.html`.

## الأمان الطبي والمحتوى

- يحتوي الموقع على تنبيه واضح بأن المحتوى للتوعية العامة ولا يغني عن التقييم الطبي المباشر، وتوجيه لأقرب قسم طوارئ في الحالات العاجلة (بعد الواجهة الرئيسية، وفي الأسئلة الشائعة، وفي التذييل).
- كل النصوص الطبية عامة وغير تشخيصية، ولا تتضمن وعودًا بالشفاء أو مقارنات مع أطباء آخرين.
- إن أردت إضافة رقم إسعاف محلي فأضفه في تنبيه الطوارئ بعد التأكد من صحته.

## الأداء وإمكانية الوصول وSEO

- لا توجد مكتبات JavaScript أو CSS خارجية، والمصدر الخارجي الوحيد هو خط Cairo. ولاستضافته ذاتيًا نزّل ملفات الخط وأضف `@font-face` في `styles.css` ثم احذف روابط Google Fonts من `index.html`.
- HTML دلالي، وروابط تخطي للمحتوى، وحالة تركيز ظاهرة للوحة المفاتيح، وقائمة موبايل بـ `aria-expanded`، ورسائل خطأ مرتبطة بالحقول.
- تُحترم `prefers-reduced-motion`: تتوقف الحركات والتمرير السلس لمن فعّل تقليل الحركة.
- عنوان الصفحة ووصفها وOpen Graph وبيانات `schema.org` الأساسية (الاسم والمسمى والهاتف فقط) وإعدادات `robots` موجودة في `<head>`.
- بعد النشر يُنصح بإضافة ملف `sitemap.xml` وتسجيل الموقع في Google Search Console.
